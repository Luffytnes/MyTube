# Audit MyTube — octobre 2026

Audit complet du dépôt (backend lu intégralement, frontend, infrastructure, CI),
complété par des tests réels : lecture vidéo dans WebKit (codecs H.264/AAC),
captures d'écran Chromium, appels à YouTube, YouTube Music et Radio Browser.

Tous les points marqués ✅ sont corrigés sur `main`, couverts par des tests
(172 tests backend, dont 41 nouveaux dans `backend/tests/test_hardening.py`)
et vérifiés par la CI, dont le test de fumée Docker.

## Critique / élevé

| Problème | Impact | Correction |
|---|---|---|
| Next.js 14.2.30 — RCE non authentifiée (GHSA-2xp9-vwfh-vxw4), aucun correctif 14.x | Exécution de code sur le conteneur frontend | ✅ Next.js 15.5.28 + React 19 |
| nginx envoyait `/api/yt/*` vers FastAPI au lieu de Next.js | En Docker : recherche, pages vidéo, chaînes et playlists en 404 | ✅ `location /api/yt/` vers le frontend + test de fumée |
| yt-dlp sans runtime JavaScript (défi « n » de YouTube) | URLs bridées sous le temps réel (lecture qui bloque), formats masqués | ✅ `yt-dlp[default,deno]`, vérifié par `/api/health` et la CI |
| Le lecteur demandait le format 18 (pré-muxé), souvent absent côté yt-dlp | « Playback Error » sur la plupart des vidéos | ✅ format adaptatif par défaut + repli automatique |
| Saut dans la vidéo : audio et vidéo désalignés dans les segments | hls.js rechargeait 2 segments en boucle (~250 req/s), lecture figée | ✅ coupe sur l'image clé (ffprobe en parallèle) + `EXT-X-START` |
| VP9/AV1 (seuls codecs au-delà de 1080p) muxés en MPEG-TS | 1440p et 4K illisibles | ✅ segments HLS fMP4 |
| FFmpeg 7.1 (Debian) sans `-request_size` | Après un saut : 10 s de vidéo produites en 15 s (sous le temps réel) | ✅ FFmpeg 9.0 dynamique dans l'image (43 s en 15 s), compatible proxychains |
| CSRF : l'auth Basic est rejouée par le navigateur | Un site tiers pouvait téléverser une config VPN ou démarrer/arrêter le VPN | ✅ rejet des écritures cross-site (`Sec-Fetch-Site`, `Origin`) |
| XSS : les proxys relayaient le `Content-Type` amont | Page HTML arbitraire exécutée sur l'origine MyTube | ✅ `CSP: sandbox` sur toutes les réponses `/api/` + proxys d'images limités à `image/*` |
| Course entre le `DELETE` d'une session HLS et la nouvelle playlist | Session neuve tuée (systématique en dev, possible en prod) | ✅ le lecteur attend le `DELETE` |

## Faible / ergonomie

- ✅ Accueil vide pour un nouveau visiteur → tendances + bannière à la une.
- ✅ Zoom bloqué sur mobile (`maximum-scale=1`), `<html lang="en">` figé, flash de thème au chargement.
- ✅ Avatar de chaîne cassé sur la page vidéo (URL absolue préfixée par l'API).
- ✅ Raccourci de recherche `/` ou `Ctrl/⌘ K`, progression de reprise sur les vignettes.
- ✅ Refonte visuelle « Cinéma sombre » (voir le commit `feat(frontend)`).

## Points restants (non corrigés)

1. **Les routes Next.js `/api/yt` (YouTube.js) ne passent pas par le VPN.** Le
   frontend interroge YouTube directement depuis son conteneur. Pistes : exposer
   un proxy HTTP dans wireproxy et l'utiliser via `undici.ProxyAgent`, ou déplacer
   ces appels vers le backend.
2. **Cache disque VOD IPTV non borné** (`/tmp`) : les fichiers complets restent
   jusqu'à 1 h après la fin, et le téléchargement continue après l'arrêt de la
   lecture. À prévoir : plafond de taille et annulation sans session active.
   Non traité faute de serveur Xtream pour tester.
3. **Failles npm « high » restantes** (postcss, braces, postcss-selector-parser) :
   elles exigent Next 16 et Tailwind 4, deux montées majeures. La CI ne bloque
   que sur les failles critiques (il n'y en a plus).
4. **Bandes-annonces remuxées** : pas de saut possible (`Accept-Ranges: none`),
   acceptable pour des vidéos de 2 à 3 minutes.
5. **10 PR Dependabot de juillet obsolètes** : yt-dlp et React déjà mis à jour,
   lucide-react 1.x supprime les icônes de marques, TypeScript 7 non testé.
   À fermer.
6. **DNS rebinding** : la validation SSRF résout le nom, puis httpx le résout à
   nouveau. Risque faible derrière l'authentification.
7. **85 avertissements de lint** existants (`any`, `<img>`, dépendances de hooks).
